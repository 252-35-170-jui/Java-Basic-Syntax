# Java Basic Syntax Practice Assignment

A comprehensive, beginner-friendly Java repository covering the essential fundamentals of Java programming. This project is created for practicing and implementing core Java concepts step by step.

## Project Description
This repository contains runnable Java programs demonstrating basic procedural programming concepts in Java. Each file is self-contained, beginner-friendly, and accompanied by meaningful comments explaining the syntax.

## How to Compile and Run

Make sure you have the Java Development Kit (JDK) installed on your system. Verify with:
```bash
javac -version
java -version
```

### Compile any file:
```bash
javac <FileName>.java
```

### Run the compiled program:
```bash
java <ClassName>
```

### Examples:
```bash
# Compile and run the Main file
javac Main.java
java Main

# Compile and run the interactive Scanner example
javac ScannerExample.java
java ScannerExample
```
